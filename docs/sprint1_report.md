# Отчёт Sprint 1 — Core Physics

## Итог
MVP Sprint 1 реализован и **проверен прогоном на реальном движке** (Godot 4.7
wasm-headless через `tools/headless/run_smoke.sh`): `SMOKE: PASS (0 fails)`,
13 проверок.

## Баги, найденные и исправленные валидацией (то и делает её ценность)
1. **`look_at_from_position(..., y_only)`** — аргумент `y_only` существует
   только у `look_at`, и то не во всех версиях: респавн переписан на ручной
   yaw (портится меньше всего между 4.x).
2. **Знак проецирования расстояния подвески**: `d = (cp-mount)·down` (луч
   «вниз» = +Y вычитается неправильно → все хиты отбрасывались, машина ехала
   «на бампере»). Ловится только живым прогоном.
3. **Взрыв демпфера пружины** при приземлении (демпфер не ограничен силой →
   сотни g на первом тике → «ракетный старт»). Добавлен `susp_max_g` и
   асимметричный отбой (`susp_rebound_damp_mult`) — иначе «батут» на 2 м.
4. **Вырожденные квады профиля** (дубли стыковых колец) → trimesh-билдеры
   (Jolt) падали «area too small»; введён `_push_point` с дедупликацией.
5. **`SpringArm3D.hit_from_inside` не существует** (есть только у RayCast3D) —
   убрано из `camera_rig.tscn`.
6. **HUD-путь** `../../PlayerCar` → `../PlayerCar` (структура без
   промежуточного CanvasLayer-узла — скрипт висит на Control-корне).
7. Inline-сеттеры `:= false: set(v):` — не-валидный GDScript до 4.4; заменено
   на `set = _func` (проект стартует на 4.3).

## Что специально НЕ сделано в Sprint 1
* сетевые RPC/авторитарный сервер — только скелет (`get_net_state()` и т.п.);
* оружие/HP/плюшки — только сокеты Hardpoints и `add_boost()`;
* UI гаража/меню и SDK платформ;
* боты (FSM) — вход `set_external_input()` готов;
* музыка/SFX/эффекты (крючки-сигналы есть).

## Методика проверки
`tests/smoke_driver.gd`: спавн→посадка (grounded), газ (пик скорости,
дистанция), лимит 45 (+2%), руление (Δheading), занос (lateral slide), буст
(расход энергии, превышение базового лимита, соблюдение буст-лимита),
респавн (ближайший SpawnPoint + возврат на пол). Плюс регрессия генерации
арены (число треугольников). Пороги заданы с запасом под разный физ-движок
(GodotPhysics/Jolt) и любой fps.
